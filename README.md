# 🔒 나만의패스워드관리 - 안전한 로컬 패스워드 매니저

**나만의패스워드관리**는 외부 인터넷 클라우드나 중앙화 서버에 데이터를 올리지 않고, 오직 사용자의 **로컬 PC 기기 내부**에만 완벽히 암호화하여 정보를 보관하는 **보안 1등급 로컬 전용 패스워드 매니저**입니다. 

제로 디펜던시(Zero Dependency) 기반의 가벼운 프론트엔드 환경과 강력한 마스터 비밀번호 암호화 알고리즘(AES-GCM), 그리고 백그라운드 동기화를 위한 초경량 로컬 컴패니언 서버(Node.js)로 구성되어 있습니다.

---

## ✨ 핵심 기능 (Features)

* **💎 프리미엄 풀-와이드 디자인 (Glassmorphism)**
  * 답답한 좌측 사이드바 구조를 제거하고 화면 전체를 시원하게 쓰는 와이드 레이아웃입니다.
  * 상단 우측에 자바스크립트로 완벽히 통제되는 유려한 반투명(Glassmorphism) 카테고리 풀다운 메뉴가 탑재되었습니다.
* **🛡️ 강력한 오프라인 암호화**
  * 브라우저의 Web Crypto API를 사용하여 최고 보안 표준인 **AES-GCM 256비트** 방식으로 계정 데이터를 브라우저 내에서 즉각 암호화합니다.
  * 서버나 통신 패킷에는 평문 비밀번호가 절대 전송되지 않으며, 해킹 및 탈취가 원천 불가능합니다.
* **🚀 무음 백그라운드 기동 (`run_hidden.vbs`)**
  * 거추장스러운 검은색 CMD 콘솔 터미널 창을 완전히 숨기고 백그라운드에서 보안 백엔드가 알아서 조용히 실행됩니다.
* **🔌 브라우저 종료 시 자동 서버 Shutdown (Heartbeat)**
  * 브라우저 창이나 탭을 닫으면 2.5초마다 보내던 생존 신호(Heartbeat Ping)가 중단됩니다.
  * 로컬 백엔드가 이를 스스로 감지하고 **7초 이내에 서버 프로세스를 완전히 종료(`process.exit`)**하여 컴퓨터 리소스를 깔끔하게 보존합니다.
* **⚡ 스마트 텍스트 일괄 가져오기 (Smart Parser)**
  * 메모장이나 카카오톡 등에 무작위로 흩어져 기록해 둔 비밀번호 텍스트 덩어리를 분석기 창에 붙여넣기만 하면, 시스템이 이름/아이디/비밀번호/비상 연락처 등을 추출하여 일괄 등록해 줍니다.
* **🎲 강력한 패스워드 생성기**
  * 대소문자, 숫자, 특수문자를 조합하여 해독 불가능한 8~64자리의 암호학적 난수 비밀번호를 간편하게 만들어 줍니다.

## 📂 프로젝트 폴더 구조 (Project Structure)

```text
Pass_manage/
│
├── index.html          # 메인 UI 구성요소 (카테고리 드롭다운 메뉴 탑재)
├── styles.css          # 프리미엄 글래스모피즘 CSS 스타일 디자인 시스템
├── style_v2.css        # 대체용 스타일 백업 CSS 파일 (동일한 디자인 동기화)
├── app.js              # 데이터 바인딩, 검색, 렌더링 및 하트비트 송신 제어 로직
├── crypto.js           # Web Crypto API 기반 로컬 파일 암호화/복호화 모듈
│
├── server.js           # HTTP 통신 및 암호화 파일 로컬 디스크 입출력 백엔드 서버
├── run.bat             # 로컬 서버 및 브라우저 기동용 배치 스크립트 (디버그용)
├── run_hidden.vbs      # CMD 창을 완전히 감추고 무음 구동해 주는 백그라운드 런처 (권장)
├── stop_server.bat     # 백그라운드에서 돌고 있는 서버 프로세스를 강제 수동 종료하는 도구
│
├── vault.json.enc      # AES-GCM 256bit 알고리즘으로 완전 무장된 암호화 금고 파일
│
└── doc/
    └── walkthrough.md  # 상세 UI/UX 개편 및 서버 라이프사이클 개발 기록서
```

## 💻 설치 및 사용 방법 (How to Run)

### 1. 사전 요구사항
* 로컬 컴퓨터에 **[Node.js](https://nodejs.org)**가 설치되어 있어야 합니다. (추가 패키지 설치는 일체 필요하지 않습니다.)

### 2. 프로그램 실행 (추천)
1. 폴더 루트 내의 **[run_hidden.vbs](file:///d:/Pass_manage/run_hidden.vbs)** 파일을 더블클릭합니다.
2. 검은색 콘솔 터미널 창 없이 무음으로 서버가 구동되고, 기본 웹 브라우저가 열리며 패스워드 매니저 화면으로 바로 진입합니다.
3. 처음 실행하시는 경우 마스터 비밀번호를 등록하여 새로운 금고 파일(`vault.json.enc`)을 생성하며, 기존 사용자의 경우 설정한 마스터 비밀번호를 입력하여 잠금을 해제합니다.

### 3. 프로그램 종료 방법
* **그냥 켜져 있는 패스워드 매니저 브라우저 창(혹은 탭)을 닫아주세요.**
* 브라우저가 닫히면 7초 이내에 백그라운드 서버가 알아서 생존 신호 끊김을 인지하고 완전 자동 종료됩니다.
* *(비상 시 백그라운드 서버가 계속 살아있다면 **[stop_server.bat](file:///d:/Pass_manage/stop_server.bat)**를 실행해 수동으로 즉시 끌 수 있습니다.)*

## 🔒 보안 핵심 설계 (Security Design)
* **Zero-Knowledge**: 사용자의 마스터 비밀번호는 메모리 상에서 세션이 유지되는 동안에만 존재하며, 그 그 어떤 쿠키나 로컬 스토리지, 물리 파일에도 평문 저장되지 않습니다.
* **Local-Only**: 모든 데이터는 `vault.json.enc` 암호화 파일 하나에만 누적 보관되므로 컴퓨터 분실/도난 시 마스터 비밀번호가 유출되지 않는 한 외부 해킹은 절대 불가능합니다.
